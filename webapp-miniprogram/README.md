# 患者端微信小程序壳工程（web-view 承载 H5）

> 说明：患者端主体为响应式 H5（`dist/`），本目录提供微信小程序壳工程，通过 `web-view` 承载，实现"小程序入口 + 原生分享 + 订阅消息"体验。

## 为什么用 web-view 而非原生
- 原生小程序发布需要：企业主体 AppID、域名 ICP 备案、HTTPS、医疗类目资质、微信审核（周期 1–3 周）。
- web-view 壳工程可在**资质齐备后 1 天内**上线，且 H5 已覆盖推荐的全部交互（语音播报/语音识别/症状上报/AI 问答）。
- 后续如需订阅消息、离线缓存、原生录音，可逐步把关键页面迁移为原生组件。

## 目录结构

```
webapp-miniprogram/
├── app.json          # 小程序配置
├── app.js

├── pages/
│   └── web/index.js|.wxml|.json

```

## 上线步骤

1. **准备域名**：H5 部署到已备案域名（例：`https.example-hospital.com/daychemo/`），并完成 HTTPS。
2. **小程序后台配置**：开发管理 → 开发设置 → 业务域名，添加上述域名（需下载校验文件放至站点根目录）。
3. **替换域名**：修改 `pages/web/index.js` 中的 `H5_BASE`。
4. **订阅消息**（可选）：在小程序后台申请模板（复查提醒/预警提醒），由后端调用 `subscribeMessage.send`。
5. **提交审核**：医疗健康类目需提供服务资质（《医疗机构执业许可证》）。

## 注意
- `web-view` 内不支持部分 API（如 `<input type=file>` 拍照上传），需要上传检验单照片时建议独立开发原生页。
- iOS 微信内语音播放需用户首次点击触发，H5 已通过"语音播报"按钮满足该约束。
- 语音识别在微信内置浏览器上依赖系统能力，部分安卓机型不可用；H5 已自动降级为文字输入。
